Real-Time Vehicle Tracking System

Tracking buses across Himachal Pradesh — live and in real time

About This Project

This system tracks the real-time location of government buses operating across the districts of Himachal Pradesh. Passengers can view live bus positions, estimated arrival times, and route information — all from their browser, without installing any app.

Built as a college project using Node.js, Express.js, and vanilla JavaScript.
